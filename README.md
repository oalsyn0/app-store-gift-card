## 税费和余额：两种说法，怎么处理

关于税，网上有两种说法，指向的环节不一样。

一种来自官网购卡流程：税发生在买卡环节，账单地址在免税州就是 0 税，$10 的卡实付 $10。另一种来自卡密平台的商品说明：兑换时 Apple 会按 Apple ID 注册州的税率从卡面值里扣税，比如 $10 卡在加州实际到账约 $9.21，余额不足不属于售后范围。第二种说法是平台免责声明的转述，没有 Apple 官方依据。

实际操作上不用纠结哪种说法对。订阅前先看账户页显示的实际余额，按余额决定买多大面额，并且在预期扣款金额上多留两三美元。订阅 $9.99 的服务，别拿 $10 卡去卡线。

另外两条来自单一来源、未核验的说法，碰到时以实际页面为准：Apple 账户余额不能用于新开 AppleCare+，也不能用来给他人发送礼品卡，这两件事需要绑信用卡。
